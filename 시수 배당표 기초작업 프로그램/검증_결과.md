# 수업시수배당표 6.5 검증 결과 (2026-11-22)

- Apps Script(모의 시트): 토큰 인증, 저장·읽기, 동시 저장 충돌 차단(409), 학생 명단 저장 거부, 저장한 선생님 이름 기록, 80번 연속 저장 시 오래된 저장본 정리 후 최신본 정상 읽기
- Netlify 함수: 설정 여부 확인(status)에 비밀값 노출 없음, 설정 없으면 차단, 틀린 비밀번호는 Google 호출 전에 거절, 맞으면 서버 토큰으로만 중계(브라우저가 보낸 주소 무시), 충돌 409 유지, 토큰 불일치 안내

## 통합 시험 (로컬 서버 + 실제 Netlify 함수 + 모의 Google 시트, 브라우저 2개)
- 처음 열면 비밀번호 창 → 틀린 비밀번호 안내 → 맞는 비밀번호로 시작
- A가 편제표를 올리면 2~3초 안에 자동 저장(저장한 사람: 김남훈)
- B가 처음 접속하면 A의 자료를 자동으로 받음(과목 59개 일치)
- B가 고친 내용이 A 화면에 자동 반영 + "주지훈 님이 고친 내용을 불러왔어요"
- 두 사람이 동시에 고치면 늦은 쪽에 "겹침" 창 → [내 자료로 덮어쓰기] 후 양쪽 자료 일치
- 다시 열어도 비밀번호를 묻지 않음
- 서버 연결이 끊기면 "연결 끊김 · 이 컴퓨터에만 저장됨" → 다시 연결되면 자동으로 올림
- 실제 파일 5개(2025·2026·2027 편제표, 2027 2·3학년 배정내역)로 1~7단계 전체 진행, 오류 없음
