# 방산고 수업시수배당표 6.5 | GitHub → Netlify → Google Apps Script / Sheets

**편제표·리로스쿨 배정내역으로 수업시수배당표 기초자료를 만들고, 여러 선생님이 여러 컴퓨터에서 함께 쓰는 웹 프로그램**

## 0. 6.5에서 바뀐 점

- **단계별 화면**: 1 학년도 선택 → 2 편제표 올리기 → 3 과목·전공 확인 → 4 선택과목 반편성 → 5 정원·창체 배분 → 6 교사 배정 → 7 결과 확인·출력. 단계마다 할 일과 진행 상태(✓)가 보입니다.
- **쉬운 말**: 사용자 화면에서 JSON·백업·Netlify·Google 같은 말을 뺐습니다. 관리용 기능은 ⚙ 설정에 있습니다.
- **전공없음**: 전공 드롭다운의 '전공없음 (정원 제외)'은 정원 계산에서 빠지고, 6단계에서 아무 교사에게나 배정할 수 있습니다. (예전 '온라인'·'공동배분' 과목은 자동으로 전공없음으로 바뀝니다.)
- **자동 저장(함께 쓰기)**: 선생님은 컴퓨터마다 **학교 공용 비밀번호를 처음 한 번만** 넣습니다. 그 뒤로는 고칠 때마다 2~3초 안에 자동 저장되고, 다른 선생님이 저장한 내용은 20초 안에 자동으로 들어옵니다.
  - 두 사람이 동시에 고쳐 저장이 겹치면 **덮어쓰지 않고** "누구 자료를 남길지" 묻습니다.
  - 인터넷이 끊기면 그 컴퓨터에 저장해 두었다가 다시 연결되면 올립니다.
  - Apps Script 주소와 토큰은 Netlify 서버에만 있고 브라우저에는 나가지 않습니다. 브라우저는 비밀번호 자체가 아니라 SHA-256 값만 기억합니다.
  - Google 시트에는 최근 저장본 40개만 남기고 오래된 저장본은 자동으로 정리합니다.

> **중요:** 공용 비밀번호 방식은 학교 Google 계정 로그인만큼 강한 인증은 아닙니다. 비밀번호는 담당 선생님들께만 알려 주고, 학생 이름·학번이 든 리로스쿨 원본 엑셀은 저장하지 않습니다(과목별 분반 수·인원만 저장). 교사 이름을 Google 시트에 두는 것이 학교 규정상 괜찮은지 확인해 주세요.

## 1. 프로젝트 구조

```
.
├── netlify.toml                  # GitHub 연동 배포 (publish = site), /api/sync → 함수
├── site/
│   ├── index.html
│   └── assets/
│       ├── steps.js / steps.css  # 6.5 단계별 화면 (학년도·편제표·전공 확인·출력·설정)
│       ├── app.js                # 계산·편제표·리로스쿨·배당표·엑셀
│       ├── cloud.js              # 6.5 자동 저장(함께 쓰기)
│       ├── storage.js            # 이 컴퓨터(브라우저) 저장
│       └── styles.css / cloud.css
├── netlify/functions/sync.mjs    # 비밀번호 확인 + Apps Script 중계
├── google-apps-script/Code.gs    # Google 시트 저장·잠금·이력·오래된 저장본 정리
├── scripts/generate-tokens.mjs   # 서버 토큰 생성
├── tests/                        # npm test
└── backups/                      # 수정 전 원본 (Git에 올라가지 않음)
```

## 2. 처음 한 번: 관리자 설정 (약 15분)

### 2-1. Google 스프레드시트 + Apps Script
1. 학교 계정으로 **빈 Google 스프레드시트**를 만듭니다. 주소 `…/spreadsheets/d/XXXX/edit`의 `XXXX`가 SHEET_ID입니다.
2. `확장 프로그램 → Apps Script`를 열고 `google-apps-script/Code.gs` 전체를 붙여 넣고 저장합니다.
3. `npm run tokens`(또는 아무 32자 이상 무작위 문자열)로 토큰 2개를 만듭니다.
4. Apps Script `프로젝트 설정 → 스크립트 속성`에 `SHEET_ID`, `TOKEN_A`, `TOKEN_B`를 넣습니다.
5. `배포 → 새 배포 → 웹 앱`, **실행: 나**, 접근 권한은 학교 정책에 맞게(외부 호출이 가능해야 합니다). 나온 `/exec` 주소를 복사해 둡니다.

> **6.4에서 올리는 경우:** Code.gs가 바뀌었으므로 붙여 넣은 뒤 `배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포`를 꼭 눌러 주세요. 주소는 그대로입니다.

### 2-2. Netlify 환경변수 (Site configuration → Environment variables, Functions 범위)

| 이름 | 값 |
|---|---|
| `GAS_WEBAPP_URL` | 위 Apps Script `/exec` 주소 |
| `GAS_TOKEN` | 스크립트 속성 `TOKEN_A`와 **같은 값** |
| `SCHOOL_PASSWORD` | 선생님들께 알려 줄 학교 공용 비밀번호 (8자 이상) |

환경변수를 바꾼 뒤에는 Netlify에서 **다시 배포(Trigger deploy)** 해야 적용됩니다.

### 2-3. GitHub → Netlify
- Private 저장소에 이 폴더 전체를 올리고, Netlify에서 그 저장소를 연결합니다. Publish directory = `site`, Functions directory = `netlify/functions` (netlify.toml에 들어 있음).
- 이후 GitHub `main`에 올리면 자동 배포됩니다. 학년도 자료는 Google 시트에 있으므로 프로그램을 고쳐 올려도 자료는 그대로입니다.
- Netlify Drop(폴더 끌어다 놓기)으로는 자동 저장이 동작하지 않습니다(함수가 빠짐).

## 3. 선생님 사용 순서

1. 사이트를 열면 **학교 비밀번호**와 이름(선택)을 넣는 창이 뜹니다. 컴퓨터마다 처음 한 번만 넣습니다.
2. 화면 위 단계(1~7)를 차례대로 따라갑니다. 고칠 때마다 위의 저장 표시가 `저장 중…` → `✓ 저장됨 · 시각`으로 바뀝니다.
3. 저장 표시를 누르면 마지막으로 저장한 사람·시각과 최근 저장 기록이 보입니다.
4. `⚠ 확인 필요 · 다른 선생님과 겹침`이 뜨면 창에서 **누구 자료를 남길지** 고릅니다. 걱정되면 먼저 [내 자료를 파일로 먼저 저장]을 누릅니다.
5. 공용 컴퓨터라면 다 쓴 뒤 저장 표시 → [이 컴퓨터에서 함께 쓰기 끄기]를 누릅니다.

## 4. 운영·보안 메모

- 비밀번호를 바꾸려면 Netlify의 `SCHOOL_PASSWORD`만 바꾸고 다시 배포합니다. 각 컴퓨터에는 다음 저장 때 새 비밀번호를 묻는 창이 뜹니다.
- 토큰이 새었다면 Apps Script 스크립트 속성 `TOKEN_A`와 Netlify `GAS_TOKEN`을 함께 새 값으로 바꿉니다.
- 비밀번호를 틀리면 응답을 0.4초 늦춰 마구 넣어 보기를 어렵게 했습니다. 더 강한 보호가 필요하면 학교 Google 계정 로그인 방식으로 바꿔야 합니다.
- `CG_Head`, `CG_Payload`, `CG_History` 시트는 직접 고치지 마세요. 저장 기록(`CG_History`)은 계속 쌓이니 가끔 오래된 줄을 지워도 됩니다.
- 서버 연결이 안 될 때도 각 컴퓨터에는 저장돼 있으며, ⚙ 설정 → [작업 파일로 저장]으로 파일을 받아 둘 수 있습니다.
